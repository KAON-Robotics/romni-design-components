<Title>ROMNI Design Components</Title>

<Subtitle>Shared React components for ROMNI Edge and Region</Subtitle>

## Install

```sh
pnpm add github:KAON-Robotics/romni-design-components#v0.1.4
```

## Usage

```tsx
import { Button, InfoTable, SelectBox } from "@romni/design-components";
```

Every public component includes interactive stories, generated API documentation, accessibility checks, and browser-based component tests.

## Development

```sh
pnpm storybook
pnpm test:storybook
pnpm test:storybook:coverage
pnpm build-storybook
```

Use Controls to inspect props and Viewports to verify mobile, tablet, and desktop behavior. Visual regression publishing runs through Chromatic when `CHROMATIC_PROJECT_TOKEN` is configured.
